# Reemplazar imágenes

Todas las fotos son archivos locales, no enlaces externos.

- `protesis.jpg`: imagen principal de la página. Reemplázala conservando el nombre.
- `proceso/01-ensamblaje.jpg`: primera imagen del carrusel. Puedes reemplazarla por tu foto del proceso conservando el nombre.
- `proceso/02-electronica.jpg`: segunda imagen. Puedes reemplazarla por una foto de la cartulina conservando el nombre o renombrarla a `02-cartulina.jpg`.

El carrusel descubre automáticamente los archivos JPG, JPEG, PNG, WebP y AVIF de la carpeta `proceso`. Puedes añadir más imágenes o eliminar las ilustrativas. Los nombres determinan el orden y el título: por ejemplo `03-pruebas-de-agarre.jpg`.

Las imágenes iniciales son ilustraciones generadas, no fotografías del proyecto real. Cuando añadas las fotos reales, actualiza las notas que las identifican como ilustrativas en las páginas de inicio y proceso.
